# Learnova - E-learning Platform
Your Personalized E-Learning Companion

Learnova is a responsive e-learning platform designed to help students explore courses, track their progress, and learn via embedded video content — all in one place.

## 🌟 Features
- Browse available courses with details and thumbnails
- Track your learning progress for each course
- Watch lessons directly via embedded video players
- Search and filter through the course list
- Fully responsive and user-friendly design

## 🛠 Tech Stack

**Frontend:**
- React.js
- JavaScript

## Install dependencies
npm install

## Run the development server
npm start
